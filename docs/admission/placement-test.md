# Q10. 新生入学有摸底考试吗？考不好会影响我后续的学习吗？

新生开学后，将会安排数学分级考试和英语分级考试，考试目的在于根据学生的水平分级教学。英语考试可能是线上，也可能是线下，若线下考试，则需注意携带个人一卡通和书写黑色字迹的签字笔、2B 涂卡铅笔、橡皮、①3.5mm 插孔有线耳机+收音机/② 二合一式的可调频头戴式耳机（二选一即可，建议 ①，英语考试使用，播放听力时频段为 FM87.0MHz），要保证在考试之前给收音机充满电，防止听了听到一半出现收音机没电的情况。

数学开学考试为高中内容，难度低于高考；英语开学考试为 1 套四级题目。依据开学摸底考试结果，按照排名比例，数学将分为 A、B 两个等级（2:8），英语将分为 A+，A，B，C 四个等级（1:4:4:1）。在实际教学过程中，数学分级没有差别，英语分级的 A+、A、B 三个级别也没有差别，语言类修读学分下限为 8 学分，无上限。

不必为你考了 A+，A 而沾沾自喜，也不必因为你是 B，C 就低人一等，开学考试的目的只是为了分级教学，无论是哪一级，“大学英语”系列课程考试用的卷子是一样的。

C 班人现身说法：我感觉 C 级挺好的，我们只要修简单的、特别水的课，A 班大佬的课很难。

英语不同分级的选课要求（数学强基除外）见下表：

| 等级 | 学分要求                                                                                         |
| ---- | ------------------------------------------------------------------------------------------------ |
| A+   | 理解当代中国（2 学分）+大学英语（高阶）（2 学分）+拓展提高类（4 学分）                           |
| A    | 理解当代中国（2 学分）+大学英语 Ⅲ（2 学分）+拓展提高类（4 学分）                                 |
| B    | 理解当代中国（2 学分）+大学英语 Ⅱ（2 学分）+核心能力类（2 学分）+拓展提高类（2 学分）            |
| C    | 理解当代中国（2 学分）+大学英语（基础）Ⅰ、Ⅱ（4 学分）+核心能力类（2 学分）或拓展提高类（2 学分） |

对于数学与统计学院培养的数学强基班，只需修读 4 学分。

数学强基班可选择修读 4 学分但需通过英语四级考试或托福取得 80 分或雅思取得 6.0 分，或选择修读 8 学分。选课要求见下表：

| 等级 | 数学强基班学分要求                                      |
| ---- | ------------------------------------------------------- |
| A+   | 理解当代中国（2 学分）+大学英语（高阶）（2 学分）       |
| A    | 理解当代中国（2 学分）+大学英语 Ⅲ（2 学分）             |
| B    | 理解当代中国（2 学分）+大学英语 Ⅱ（2 学分）             |
| C    | 大学英语（基础）Ⅰ（2 学分）+大学英语（基础）Ⅱ（2 学分） |

关于课程分类：之前把语言类课程分为大学英语、核心能力、拓展提高三类，自 2025 级起，按具体内容分为语言能力、国际视野（理解当代中国及小语种如日语等）、人文素养、专业发展四个模块，其中大学英语、核心能力和部分拓展提高均属于语言能力模块，此处为便于理解，仍采用之前的分类。

可以看到，在新版培养方案中，对 2025 级本科生，任何英语分级均不必须修读核心能力类，故不建议任何分级的同学选核心能力类课程（仅 1 学分，需要选两个，考两次试）。

有的人说英语不同分级的给分情况有差别，事实上这是错误的，因为在给分的问题上，老师的差别远远大于分级的差别，要是希望得高分，无论哪个分级都需要选一个给分好的老师。

软件学院有二次选拔的拔尖班，希望进入拔尖班的软件学院同学，应当好好复习一下高考数学（重点训练熟练度准确度，非常困难的题目例如 2022 年浙江高考压轴题这种不用看），从而应对新生数学分级考试。
