# Q17. 学校的校园网怎么连接？需要办理校园卡吗？

首次使用校园网，需要创建深澜上网账号（流程为：翱翔门户 → 上网账号创建，具体流程见附件 12）。长安校区所有教学区、学院楼、图书馆、食堂覆盖有“NWPU-FREE”公共免费网络（连接后需要认证登录，账号用户名为学号，密码为创建上网账户时设置的密码），在宿舍可以使用“NWPU-WLAN”收费网络，其余地方（比如校园道路上）只能使用流量（不绝对，也有可能有 NWPU-FREE）。

请注意，任何以无法上网为借口要求你办理校园卡、电话卡的人员均视为诈骗。校园网计费系统为深澜计费系统，可在翱翔门户或西北工业大学 APP 进行缴费，无需额外办理其他服务！

（上网账号可以先创建，但是建议 9 月 1 号以后再缴费，不然相当于白交了一个月网费）
