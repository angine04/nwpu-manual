# Q16. 为什么我进入学校后，有这么多自称市场营销专业的大三大四学姐向我推销笔？

上大学第一课：防诈骗！

开学季骗术大总结：

1．无缘无故拉你进别的群的；
2．用网图女头假装学姐私信你要帮忙的；
3．任何在网上卖东西的，包括卖笔、卖英语课、卖学习资料、卖各种培训网课的；
4．动机不明莫名其妙加你好友私聊你的；
5．（针对你本人是女同志，但有学长莫名其妙加你的情况）即使对方表明身份确实是西北工业大学学生且可以验证的，也不要轻易同意对方的好友申请。

骗子要素：网图女头，主页空白，QQ 等级较低，随意拉群，无故或一上来就私信加好友，自称是某非理工科专业的大三大四学姐，以上六点占一点以上基本上可以判定是骗子。

一般而言，主动上前来找你推销的，都可以视为诈骗，最好一律拒绝。校园内常见的诈骗包括办电话卡、办校园卡、买水票、推销笔、交流口语。

伸手要钱的都慎重考虑，其实有些东西没必要，我就分享自己之前差点报名一个口语班。就是在路上可能会有人突然用英语和你交流，然后会跟你说他们是学校口语部的。他还会跟你宣传英语口语很重要啦，好多同学每天早上都会在他们的群里打卡英语口语等等。这个东西还是要看你的需求的，老东西只是想说明下，第一，我那次特地问了班主任，明确口语部不属于学校官方；第二，这个口语课报名费对于大部分大学生来说还是有点贵的（大概六七千），慎重对待父母的钱！（格温的真实经历）。

遇到上门推销，不要害怕。拒绝他们并没有什么不好，直接关门。这些人会用话术忽悠你电话卡是校园卡，请注意，西工大只有一卡通，没有校园卡这一说法。学校从来没有发过不办理校园卡就不能用校园网这种通知，千万别信，卖其他东西的一律别信。大学生要学会的第一课就包括要学会拒绝别人，脸皮适当的厚一点。如果是卖桶装水（后勤集团指定“秦岭龙泉”和“恒大”）的话跟舍友商量一下，现在有学校监管，送水上楼，其实挺方便的。

购买桶装水水票，不要买“绿沣”。
