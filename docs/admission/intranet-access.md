# Q12. 如何访问校内网站？

使用 SSLVPN 客户端（EasyConnect）。师生在未连接校园网的情况下如需访问校内网资源，请使用 VPN 方式。在浏览器输入 https://vpn.nwpu.edu.cn/portal/#!/login 并下载 EasyConnect 客户端，使用翱翔门户账户登录即可使用。

使用 WebVPN 网页版。在浏览器输入 WebVPN 网站 https://webvpn.nwpu.edu.cn，直接跳转至翱翔门户统一身份认证登录页面，输入翱翔门户账户、口令登录进入 WebVPN 资源页面。用户也可选择使用“扫码登录”和“验证码登录”。

翱翔门户中的 “翱翔教务”等大部分不需要挂 VPN 也可以使用，仅“智慧党建”等少数模块需要挂 VPN。
