# Q5. 新生入学在哪一个校区？

新生入学统一在西北工业大学长安校区。航空，民航，材料，机电，QM 的材料部分在大三或大四会搬回友谊校区，部分专业本科做毕业设计时会前往太仓智慧港。在夏季学期也可选择修读某些开设在太仓智慧港的课程，短暂体验（你问太仓校区为什么不招本科生？请看附件 1）。
