# Q69. 学校里面有猫吗？

有，大多为流浪猫。学校位于秦岭脚下，生态环境较好，学校里面的各种动物自然也不少，不仅有猫，还有各种鸟类、狗等等。需要强调的是，这些生物中间是存在显性和隐性的食物链的，相信大多数同学都有一份自然的爱护小动物之心，所以请各位同学在遇到猫狗时，做到不投喂未绝育的流浪猫狗，要不然报告学校的动保协会进行绝育/驱赶处理（有的猫狗对外会表现强烈的攻击性，最近学校有只狗先后攻击/攻击致死/吃掉了近 20 只流浪猫，见血的狗大概率也会袭击人），要不然自行花钱绝育/领养，维护学校的生态平衡。而在春天是“青鸟”红嘴蓝鹊的繁殖季节，它们的领地意识和对巢穴的保护欲望非常强烈，所以当它们把巢穴筑在道路两旁的树上时，人经过时很可能会遭到其袭击，如果你不幸遭遇了袭击，请及时向保卫处反映，由专业人员对红嘴蓝鹊进行移巢处理，同时确保自身并未受伤，如被啄伤一定要及时处理伤口以防感染。
