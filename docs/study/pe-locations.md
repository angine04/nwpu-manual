# Q42. 体育课的上课地点都在哪里？我该怎么过去？

篮球：星天苑篮球场；
排球：翱翔体育馆副馆；
足球、极限飞盘：星天苑小足球场；
羽毛球：翱翔体育馆主馆/副馆；
乒乓球：综合体育馆（官名体育部综合楼，俗称小黄楼，位于星操西北）一楼；
网球：星天苑网球场；
橄榄球、定向越野：星/云天苑操场；
健美操、啦啦体操、健身瑜伽、健身街舞：综合体育馆三楼形体室；
武术：翱翔体育馆二楼外围南/翱翔训练馆篮球场（友谊校区）；
游泳：翱翔游泳馆（位于星操南侧）室内游泳馆；
跆拳道、拳击运动：翱翔体育馆自卫防身室；
体育舞蹈、拉丁舞：翱翔体育馆 103；
中国式摔跤：翱翔游泳馆室外游泳池；
翱翔国防体育（陈班和航空航天强基班内置课）：综合训练场（位于星操西侧，小黄楼南边）；
击剑：翱翔体育馆二楼外围北；
舞龙：云天苑操场跑廊；
男子健美：综合体育馆二楼健身室；
体适能基础、身体素质课：星天苑操场；
匹克球：海天苑匹克球场。
